# 📋 Gerenciador de Tarefas em C#

Um sistema simples e funcional de gerenciamento de tarefas desenvolvido via console (CLI) utilizando a linguagem C#. Este projeto foi construído com foco em lógica de programação, manipulação de coleções (`List<T>`), estruturas de repetição e refinamento de interface de usuário.

# Funcionalidades

- **Adicionar Tarefa:** Permite cadastrar novas atividades na lista.
- **Listar Tarefas:** Exibe todas as tarefas registradas numeradas por índices.
- **Remover Tarefa:** Permite excluir atividades de forma segura utilizando o índice correspondente.
- **Validação de Entradas:** Tratamento de erros e verificação de índices inválidos.
- **Interface Limpa:** Navegação fluida com limpeza de tela e pausas para leitura.

# Tecnologias Utilizadas

- **C#** (.NET)
- **Conceitos aplicados:** `do-while`, `switch-case`, `List<T>`, laços `for`, validações condicionais e tratamento de fluxo de console.
